# Tipos de prueba

Las pruebas son procedimientos utilizados para evaluar conocimientos, habilidades y fenómenos. Permiten obtener información y comprobar resultados mediante diferentes métodos.

## 1. Prueba teórica

Es una evaluación que permite comprobar los conocimientos y conceptos que una persona ha adquirido sobre un determinado tema. Se centra en la comprensión de definiciones, principios, fundamentos y teorías.

**Ejemplo:** responder un cuestionario sobre conceptos de matemáticas, física o ciencias.

## 2. Prueba práctica

Es una evaluación que permite demostrar la capacidad de aplicar los conocimientos adquiridos mediante la realización de actividades o tareas concretas.

**Ejemplo:** resolver un ejercicio matemático aplicando fórmulas y procedimientos aprendidos.

## 3. Prueba experimental

Consiste en realizar experimentos bajo condiciones controladas para observar resultados, comprobar hipótesis y analizar el comportamiento de diferentes variables.

**Ejemplo:** realizar un experimento científico para comprobar cómo influye la temperatura en un fenómeno.

## 4. Prueba observacional

Consiste en recopilar información mediante la observación directa de un fenómeno, comportamiento o situación, sin intervenir directamente en las condiciones estudiadas.

**Ejemplo:** observar el crecimiento de una planta y registrar los cambios que presenta durante varios días.
